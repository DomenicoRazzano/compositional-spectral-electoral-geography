Public harmonized dataset
This directory contains the public-release version of the harmonized electoral archive.
Stored directly in the repository:
```text
camera_all_harmonized_public.rds
```
Distributed through the latest GitHub release:
```text
camera_all_harmonized_public.csv
```
Both files contain the same public-release table in different storage formats.
The dataset is generated by:
```text
06_code/99_public_dataset.R
```
For provenance and the complete data-directory documentation, see `../README.md`.
