# Public harmonized dataset

This directory contains the public-release version of the harmonized electoral archive used by the project.

## Files

The repository directly contains the RDS representation:

```text
camera_all_harmonized_public.rds
```

The equivalent CSV representation is substantially larger and is therefore distributed through the [latest GitHub release](https://github.com/DomenicoRazzano/compositional-spectral-electoral-geography/releases/latest):

```text
camera_all_harmonized_public.csv
```

The RDS and CSV files contain the same public-release dataset in different storage formats.

The RDS file is preferable for use in R because it preserves column types and is substantially more compact. The CSV version is provided as a software-independent tabular representation for users who do not work in R.

## Generation

The public dataset is generated by:

```text
06_code/99_public_dataset.R
```

from the harmonized analytical archive produced by the upstream cleaning and territorial-harmonization stages.

The public dataset is therefore a derived output of the reproducible pipeline rather than a separately maintained data source.

For the complete description of the source data, territorial harmonization, and data flow, see [`../README.md`](../README.md).
