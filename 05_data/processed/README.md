# Processed data

This directory is generated by the replication pipeline and is intentionally not stored in full in ordinary Git history.

The complete generated directory is distributed through the [latest GitHub release](https://github.com/DomenicoRazzano/compositional-spectral-electoral-geography/releases/latest) as:

```text
processed\\\_data\\\_complete.zip
```

It contains the cleaned, analytical, harmonized, compositional, spectral, validation, and audit objects generated by the scripts in `06\\\_code/`.

Principal generated objects include:

```text
camera\\\_all\\\_processed.\\\*
camera\\\_all\\\_analytical.\\\*
camera\\\_all\\\_harmonized.\\\*
compositional/stage04\\\_composition\\\_distance\\\_objects.rds
spectral/
validation outputs
audit outputs
```

The same files can be reconstructed by running:

```r
source(here::here("06\\\_code", "run\\\_all.R"))
```

For the complete data structure and provenance, see [`../README.md`](../README.md).
