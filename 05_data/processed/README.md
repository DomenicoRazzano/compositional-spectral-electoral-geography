# Processed data

This directory contains data objects generated by the replication pipeline. Because several of these files are large, the complete directory is not stored in ordinary Git history.

The complete processed-data directory associated with the replication release is distributed through the [latest GitHub release](https://github.com/DomenicoRazzano/compositional-spectral-electoral-geography/releases/latest) as:

```text
processed_data_complete.zip
```

## Contents

The processed-data archive contains the main intermediate and analysis-ready objects produced by the replication pipeline, including:

```text
camera_all_processed.*
camera_all_analytical.*
camera_all_harmonized.*
compositional/
spectral/
validation outputs
audit outputs
```

The principal Stage 04 serialized object is stored under:

```text
compositional/stage04_composition_distance_objects.rds
```

The `compositional/` directory contains the election-specific compositions, alternative geometry objects, pairwise distances, and related Stage 04 analytical objects.

The `spectral/` directory contains the generated graph, spectral, clustering, and temporal objects used by Stage 05.

## Reconstruction

These files are generated from the source and lookup material contained in the repository.

After restoring the R environment, the complete pipeline can be run from the repository root with:

```r
source(here::here("06_code", "run_all.R"))
```

Users who do not need to reconstruct all intermediate objects from the raw inputs can instead download `processed_data_complete.zip` from the versioned GitHub release.

For the complete description of the data structure and provenance, see [`../README.md`](../README.md).
