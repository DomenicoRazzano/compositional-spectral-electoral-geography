# Complete territorial partition atlas

The complete election-by-geometry-by-resolution atlas is
distributed as `complete_cluster_atlas.zip` in the v1.0.0
GitHub release.

The archive contains maps for all 19 elections, all six
electoral geometries, and cluster resolutions C = 2,...,8.

Selected maps used in the thesis remain directly available
under the other subdirectories of 07_outputs/figures/results/maps/.
