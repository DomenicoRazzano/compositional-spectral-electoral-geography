# Empirical outputs

This directory contains the machine-readable empirical results and supplementary figures generated by the Stage 04, Stage 05, and Results scripts.

## Structure

```text
07\\\_outputs/
├── tables/
│   ├── compositional/
│   ├── spectral/
│   └── results/
└── figures/
    ├── compositional/
    └── results/
        ├── non\\\_map/
        │   ├── core/
        │   ├── robustness/
        │   ├── graph/
        │   ├── interpretation/
        │   ├── temporal/
        │   └── appendix/
        └── maps/
            ├── main\\\_ready/
            ├── geometry\\\_comparisons\\\_C4/
            ├── transition\\\_pairs\\\_C4/
            ├── transition\\\_stories\\\_C4/
            ├── province\\\_instability/
            └── clusters\\\_all/
```

## Tables

### `tables/compositional/`

Machine-readable outputs from `04\\\_build\\\_compositional\\\_geometry.R`. They include:

* support summaries and final component classifications;
* structural-zero counts and summaries;
* component masses and clr variability diagnostics;
* power-parameter calibration profiles;
* pairwise distance summaries and full cross-geometry comparisons;
* component contributions to distances;
* zero-pattern and zero-replacement sensitivity diagnostics;
* subcomposition stability diagnostics.

Representative files:


### `tables/spectral/`

Machine-readable outputs from `05\\\_graphs.R`. They include:

* affinity/local-scale diagnostics;
* normalized-Laplacian eigenvalues;
* preferred spectral coordinates;
* fixed-`C` assignments for all geometries and resolutions;
* partition-quality diagnostics;
* component and regional cluster profiles;
* cross-geometry partition comparisons;
* adjacent-election stability;
* transition matrices;
* province-level coassignment instability.

Representative files:


`stage05\\\_fixedC\\\_cluster\\\_assignments.csv` is the principal source for the territorial cluster maps.

### `tables/results/`

Compact Results tables and manifests produced by the figure scripts. These include selected summaries, figure manifests, map display-label alignments, cross-geometry reassignment summaries, transition-change tables, and interpretation/robustness tables.

## Figures

### `figures/results/non\\\_map/core/`

Core composition and geometry figures: support dimensionality, residual support shares, zero structure, component mass versus clr variability, power calibration, and cross-geometry agreement.

### `figures/results/non\\\_map/robustness/`

Design-sensitivity figures: zero-replacement robustness, subcomposition sensitivity, and cross-geometry partition stability.

### `figures/results/non\\\_map/graph/`

Graph and spectral diagnostics: affinity diagnostics, algebraic connectivity over time, low-frequency spectrum, and multiresolution partition diagnostics.

### `figures/results/non\\\_map/interpretation/`

Election-specific interpretation outputs: spectral-axis/component relationships and cluster electoral/regional profiles.

### `figures/results/non\\\_map/temporal/`

Temporal outputs: adjacent-election partition stability, transition matrices, selected transition panels/examples, and instability summaries.

The nested `transition\\\_matrices\\\_C4\\\_all/` directory contains all adjacent-election transition matrices at `C=4`.

### `figures/results/non\\\_map/appendix/`

Supplementary full-election versions of selected robustness/geometry diagnostics.

## Map outputs

### `figures/results/maps/main\\\_ready/`

Preferred-geometry `C=4` map for every election.

### `figures/results/maps/geometry\\\_comparisons\\\_C4/`

Election-specific side-by-side comparison of:

```text
preferred Greenacre weighted power
Aitchison
Euclidean shares
```

### `figures/results/maps/transition\\\_pairs\\\_C4/`

Two-map preferred-geometry panels for every adjacent election pair.

### `figures/results/maps/transition\\\_stories\\\_C4/`

Three-panel displays with the previous partition, current partition, and label-invariant province-level coassignment instability.

### `figures/results/maps/province\\\_instability/`

Mean province-level coassignment-instability maps for each clustering resolution.

### `figures/results/maps/clusters\\\_all/`

Complete territorial partition atlas:

```text
19 elections
× 6 geometries
× 7 resolutions (C = 2,...,8)
= 798 partitions
```

Each partition is exported as both PDF and PNG, producing 1,596 files.

Because the atlas is approximately 0.9 GB, it is distributed as:

```text
complete\\\_cluster\\\_atlas.zip
```

through the [latest GitHub release](https://github.com/DomenicoRazzano/compositional-spectral-electoral-geography/releases/latest).

## File formats

Publication figures are generally exported in both PDF and PNG. Tables are stored mainly as CSV for direct inspection and reuse.
