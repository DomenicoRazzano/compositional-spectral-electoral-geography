# Empirical outputs

This directory contains the empirical results and supplementary figures generated by the compositional, spectral, and Results stages of the replication pipeline.

The numerical outputs are stored under `tables/`, while figures are stored under `figures/`.

## Structure

```text
07_outputs/
├── tables/
│   ├── compositional/
│   ├── spectral/
│   └── results/
└── figures/
    ├── compositional/
    └── results/
        ├── non_map/
        │   ├── core/
        │   ├── robustness/
        │   ├── graph/
        │   ├── interpretation/
        │   ├── temporal/
        │   └── appendix/
        └── maps/
            ├── main_ready/
            ├── geometry_comparisons_C4/
            ├── transition_pairs_C4/
            ├── transition_stories_C4/
            ├── province_instability/
            └── clusters_all/
```

# Tables

## `tables/compositional/`

Otputs generated by:

```text
06_code/04_build_compositional_geometry.R
```

These files document the construction and comparison of the electoral compositions and distance geometries.

They include:

- election-specific support summaries;
- final component classifications;
- structural-zero counts and summaries;
- component masses;
- clr variability diagnostics;
- positive-power calibration profiles;
- selected power parameters;
- pairwise distance comparisons across geometries;
- component contributions to total pairwise distance;
- zero-pattern diagnostics;
- zero-replacement sensitivity;
- subcomposition sensitivity.


## `tables/spectral/`

Outputs generated by:

```text
06_code/05_graphs.R
```

These files document the graph, spectral, clustering, geometry-sensitivity, and temporal stages of the analysis.

They include:

- locally scaled affinity diagnostics;
- normalized-Laplacian eigenvalues;
- preferred spectral coordinates;
- fixed-`C` cluster assignments for all geometries and resolutions;
- multiresolution partition-quality diagnostics;
- spectral-axis/component correlations;
- provinces at the extremes of the leading spectral axes;
- cluster electoral profiles;
- cluster regional profiles;
- cross-geometry partition comparisons;
- adjacent-election partition stability;
- transition matrices;
- province-level coassignment instability.

The principal source for all territorial cluster maps is:

```text
stage05_fixedC_cluster_assignments.csv
```

## `tables/results/`

This directory contains compact tables generated specifically for the Results chapter and supplementary material by:

```text
06_code/98_results_figures_nonmap.R
06_code/99_results_figures_maps.R
```

These outputs are derived from the canonical Stage 04 and Stage 05 tables.

They include, among other objects:

- selected power-calibration summaries;
- preferred-geometry affinity diagnostics;
- selected spectral-axis extremes;
- multiresolution summaries;
- regional-purity summaries;
- geometry-sensitivity summaries at `C = 4`;
- selected and complete adjacent-election transition summaries;
- province-level geometry-comparison records;
- province-level temporal-change records;
- display-label alignment tables used by the map-generation script;

# Figures

## `figures/results/non_map/core/`

Core figures describing the construction and behavior of the electoral space.

These include:

- electoral-support dimensionality;
- vote shares assigned to residual components;
- zero-cell prevalence and composition;
- component mass versus clr variability;
- positive-power calibration;
- pairwise agreement between electoral geometries.

## `figures/results/non_map/robustness/`

Design-sensitivity and robustness figures.

These include:

- zero-replacement sensitivity;
- subcomposition sensitivity;
- sensitivity of fixed-`C` partitions to the electoral geometry.

## `figures/results/non_map/graph/`

Graph and spectral diagnostics.

These include:

- local-scale and effective-neighborhood diagnostics;
- algebraic connectivity through time;
- the low-frequency normalized-Laplacian spectrum;
- multiresolution clustering diagnostics.

## `figures/results/non_map/interpretation/`

Election-specific interpretation figures.

These include:

- correlations between leading spectral coordinates and electoral components;
- cluster electoral profiles;
- regional allocation across spectral clusters;
- weighted regional purity through time.

## `figures/results/non_map/temporal/`

Temporal-comparison outputs.

These include:

- adjacent-election partition stability;
- transition matrices;
- selected transition panels;
- representative low-, typical-, and high-stability transition examples.

The subdirectory:

```text
transition_matrices_C4_all/
```

contains one transition matrix for every adjacent-election comparison at `C = 4`.

## `figures/results/non_map/appendix/`

Supplementary figures that provide full-election or expanded versions of diagnostics summarized more compactly in the main Results chapter.

These include:

- component mass versus clr variability for all elections;
- subcomposition sensitivity across all electoral geometries;
- election-specific distance agreement between the preferred geometry and the alternatives.

# Map outputs

Map figures are generated by:

```text
06_code/99_results_figures_maps.R
```

using the harmonized provincial assignments together with the generalized 2022 ISTAT provincial and regional geometries.

## `figures/results/maps/main_ready/`

Publication-ready maps of the preferred geometry at:

```text
C = 4
```

for every election.

These contain the same underlying partitions that also appear in the complete atlas, but use a cleaner layout intended for direct use in the thesis.

## `figures/results/maps/geometry_comparisons_C4/`

Election-specific side-by-side comparisons of the `C = 4` partitions obtained under:

```text
Preferred Greenacre weighted power
Aitchison
Euclidean shares
```

Alternative-geometry cluster labels are matched to the preferred partition by maximum provincial overlap for visual comparability.


## `figures/results/maps/transition_pairs_C4/`

Two-map panels for every adjacent election pair under the preferred geometry at `C = 4`.

Preferred-geometry display labels are aligned sequentially through time by maximum provincial overlap so that colours can be compared visually across adjacent elections.

## `figures/results/maps/transition_stories_C4/`

Three-panel displays containing:

1. the preferred partition in the previous election;
2. the preferred partition in the current election;
3. province-level coassignment instability for that transition.

## `figures/results/maps/province_instability/`

Maps of mean province-level coassignment instability for each clustering resolution.

For each province and resolution, the displayed value is the average instability across adjacent-election transitions.

## `figures/results/maps/clusters_all/`

Complete territorial partition atlas.

The atlas covers:

```text
19 elections
× 6 electoral geometries
× 7 clustering resolutions (C = 2,...,8)
= 798 partitions
```

Each partition is exported in both PDF and PNG format, producing:

```text
1,596 figure files
```

Because the complete atlas is large, it is not stored in ordinary Git history. It is distributed through the versioned GitHub release as:

```text
complete_cluster_atlas.zip
```

The release can be downloaded from the [latest GitHub release](https://github.com/DomenicoRazzano/compositional-spectral-electoral-geography/releases/latest).

# File formats

Figures are generally exported in both:

```text
PDF
PNG
```

PDF files are intended primarily for LaTeX and print-quality use, while PNG files provide convenient direct inspection and browsing.

Numerical tables are stored primarily as CSV so that the empirical outputs can be inspected without requiring R.
